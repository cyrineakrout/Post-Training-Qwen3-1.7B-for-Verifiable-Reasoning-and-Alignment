# Safety Model — Reproduction Guide

All trained models and datasets are hosted on HuggingFace:
- **Models**: `zguir23/safety-models` (all experiment models)
- **Datasets**: `zguir23/safety_data`
- **CI submission**: `cs-552-2026-camykaz/safety_model` (best model — Exp 3, 84% CI)

**Best result**: Exp 3 — Clean mix 32k, **84% CI**, 77.22% local clean accuracy.

---

## Environment

```bash
pip install -r requirements.txt
```

Key packages: `torch`, `transformers`, `peft`, `trl`, `datasets`, `huggingface_hub`.

## Evaluating the submitted model — one command

The merged model and evaluation dataset are on HuggingFace.
`download_data.py` downloads the eval set automatically on first run.

```bash
# Run from code/safety/
python scripts/download_data.py --eval_only

python scripts/eval_safety_accuracy.py \
    --model_name cs-552-2026-camykaz/safety_model \
    --data_path data/safety_eval_v2_clean.jsonl \
    --no_wandb
```

## Merging a trained adapter

After training, merge the LoRA adapter into the base model before evaluating:

```bash
# No-thinking models (Exp 1–5, DPO)
python scripts/merge_safety_lora.py \
    --adapter_path models/exp3_clean_mix_32k_best \
    --output_dir models/exp3_clean_mix_32k_best_merged

# Thinking models (T1, T2, T3)
python scripts/merge_safety_lora.py \
    --adapter_path models/thinking_t3_real_cot_distillation \
    --output_dir models/thinking_t3_real_cot_distillation_merged \
    --thinking
```

## Reproducing the datasets

The training datasets on HuggingFace were built with the scripts in
`scripts/data_processing/`. They do **not** need to be re-run to reproduce results
(the final datasets are already on HF via `download_data.py`), but are included
for full transparency.

### Individual source scripts

| Script | Dataset | Used in |
|--------|---------|---------|
| `build_beavertails_sft.py` | PKU-Alignment/BeaverTails | Exp 1–5 |
| `build_rlhf_sft.py` | Anthropic/hh-rlhf | Exp 3–5 |
| `build_social_reasoning_sft.py` | social_i_qa + ETHICS + Civil Comments | Exp 2–5 |
| `build_bbq_sft.py` | google/bbq | Exp 3, 5 |
| `build_salad_sft.py` | SALAD-Bench | Exp 3 |
| `build_wildguardmix_sft.py` | allenai/wildguardmix | Exp 4 |
| `build_dpo_dataset.py` | Hard negatives from Exp 3 predictions | DPO D1–D3 |
| `build_synthetic_cot.py` | Wraps Exp 5 data in templated `<think>` blocks | T2 |
| `build_real_cot_distillation.py` | Claude Haiku 4.5 teacher on Exp 3 questions (train only, no dev split) | T3 |
| `build_eval_set.py` | Held-out eval set (935 examples, zero train overlap) | Eval |

### Combined dataset builders

| Script | Local output (build) | HuggingFace filename | Used in |
|--------|----------------------|----------------------|---------|
| `build_dataset_exp3.py` | `combined_v10_nosb_train.jsonl` | `exp3_clean_mix_train.jsonl` | Exp 3 |
| `build_dataset_exp4.py` | `combined_v12_train.jsonl` | `exp5_large_mix_bbq_train.jsonl` | Exp 5 |

> **Note:** `build_dataset_exp4.py` is named "exp4" for historical reasons but builds
> the Exp 5 dataset (larger ~62k mix). There is no separate `build_dataset_exp5.py`.

> **Note:** Exp 2 dataset (`exp2_bt_siqa_ethics_civil_train.jsonl`) is available
> directly on HuggingFace. It was assembled from `build_beavertails_sft.py` and
> `build_social_reasoning_sft.py` outputs.
